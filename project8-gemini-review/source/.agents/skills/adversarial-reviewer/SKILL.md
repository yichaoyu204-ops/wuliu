# 立项评审

1. 写下具体使用者、付费人、触发任务、完成频率及当前交付物。把“想节省时间”还原成可以计时的起止点，如收到完整资料到操作员确认差异清单。
2. 为同一输入寻找三个可行选择：沿用当前流程、试用现成产品、做最小改动。比较相同范围的结果、准备时间、纠错成本和实际准入条件。按来源标记“实际跑过”“官方说明”“仍待核实”。检索入口见项目根目录下 `knowledge/INDEX.md`。
3. 跟着一条真实任务找最容易推翻收益假设的条件。账单审核要核对采购条款和适用期；收费场景需确认使用者能否决定购买。资料不成对时记录缺口，算例单列。
4. 提出最廉价且可判输赢的一次实验。预先写明成功、失败与无结论条件。对照同一批材料时，统计复核用时、确认差错与漏报；记录人工处理差异的代价。
5. 交付一张“选择、已有证据、关键缺口、下一步”表，明确继续、复用或暂停。只有真实付款可记为收入。样本量小或资料有偏时，写限定范围。

**示例。** 若报价表已能按 kg/lb 计费，先试同一票不同单位的输入与英文导出。只有对账仍存在无法解释的额外工时，才比较新增对账能力。
