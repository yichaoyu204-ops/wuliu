# 单据提取与复核

1. 标记文件角色（销售价表、采购约价、供应商账单、回单或示例）、币种、服务期与可见票号。先按角色分组，再将同票、同服务、同期凭证配对。
2. Excel 字段保留表名和格位，PDF 使用页码加表头及行，图片使用页次和可辨认位置。跨页续表先复核表头、币种与单位。模糊小数点、负号及零额回看原图。
3. 逐项输出字段 `raw_value`、`normalized_value`、`unit`、`source_ref`、`status`、`reason`。状态取 `confirmed`、`review` 或 `missing`。如交付要求 confidence，标注证据等级与理由；有已校准的分数才写概率。把缺失留空，与有凭据的 0 区分。
4. 保留原单位，另列换算值和费率依据。校验数量乘费率、汇总分项和总额，再查折扣、税费与四舍五入。未确认币种、合同版本或计费单位时，保留待核原因并停止该行比较。
5. 出具两个视图：可直接回查的结构化记录，和按金额影响排序的人工复核队列。疑似差异记录为待复核，展示真实客户资料时按用户指定的范围脱敏。

**示例。** F04 行只有“代收代付”、回单尚缺，应填 `normalized_value=null`、`status=missing`、`source_ref=示例条款 p1 F04`，原因写“缺仓库实收回单”。在项目 `knowledge/logistics/sample-rules.md` 可对照相关口径。
