# 本机模型辅助抽取

在本机运行的对账页面中，选择一页有可选文字的非标单据，在模型选项中填写 Ollama 本地已安装的模型名，并主动启动抽取。服务默认地址为 `http://127.0.0.1:11434`。若网页提示跨域限制，使用本机运行入口，并仅允许该入口的来源访问本机模型服务。扫描件需先取得文字或人工录入。

程序先查询模型元信息，确认可用后再提交当前页文字。返回的金额与费用名称必须同时出现在原文同一行，其他字段须能在该页找到原文片段。找到引文仅说明文字存在，费用归属与合同适用性仍需人工核实。模型超时、文档不清晰、跨行排版等情况下沿用人工核对入口。

验收命令为 `node --test ollama.test.mjs`。测试覆盖接口格式、来源过滤和失败行为，使用替身服务；模型质量另需本机模型与真实配对账单验证。
